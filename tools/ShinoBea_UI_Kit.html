7 · Rules that keep it coherent

RuleWhy
Everything at TEXEL 2Textures authored 1×, drawn 2×, nearest filter. Matches the existing sprite/tileset convention so UI and world share a pixel size.
Paper is for information, wood is for actionsIf it's readable content it sits on washi. If it's pressable it's a wooden plaque. No exceptions — this is what makes the menu legible without labels.
Red is only ever the seal and HPCinnabar carries "you / danger". Never use it for decoration.
Ink outline on every element1px ink0 border everywhere so UI survives on any biome background.
Kanji is flavour, never the only labelJapanese always pairs with the English word. Never gate meaning on a glyph.
Focus = seal + plaque swap + 2px liftThree redundant cues so controller focus is unmistakable on a TV.
Bar notches every 25 unitsReading exact HP at a glance without squinting at numbers.
